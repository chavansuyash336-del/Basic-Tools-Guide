Basic Tools Guide

Learn about common tools, their uses, types and basic safety information.

👋 Welcome

This guide introduces commonly used hand and workshop tools. Tap any tool below to learn more about it.

🔨 Hand Tools

📖 Introduction

A hammer is a hand tool mainly used for driving nails, fitting parts and performing general workshop work.

⚙️ Main Uses

  • Driving nails
  • Fitting and assembling parts
  • Light breaking work

🔧 Common Types

  • Claw hammer
  • Ball-peen hammer
  • Sledgehammer

⚠️ Safety

Hold the handle firmly and make sure the hammer head is secure before using it.

📖 Introduction

A screwdriver is a hand tool designed to tighten or loosen screws.

⚙️ Main Uses

  • Tightening screws
  • Removing screws
  • Assembly and repair work

🔧 Common Types

  • Flat-head screwdriver
  • Phillips screwdriver
  • Torx screwdriver

⚠️ Safety

Use the correct screwdriver size and avoid using a damaged or broken tip.

📖 Introduction

Pliers are hand tools used for gripping, bending, holding and cutting materials.

⚙️ Main Uses

  • Holding objects
  • Bending wires
  • Cutting wires

🔧 Common Types

  • Combination pliers
  • Long-nose pliers
  • Cutting pliers

⚠️ Safety

Do not use pliers as a substitute for a wrench or hammer.

📖 Introduction

A wrench is used to tighten or loosen nuts, bolts and other fasteners.

⚙️ Main Uses

  • Tightening nuts
  • Loosening bolts
  • Mechanical maintenance

🔧 Common Types

  • Open-end wrench
  • Ring wrench
  • Adjustable wrench

⚠️ Safety

Select the correct size and keep the wrench properly aligned with the fastener.

📏 Measuring Tools

📖 Introduction

A measuring tape is a flexible measuring instrument used to determine length and distance.

⚙️ Main Uses

  • Measuring length
  • Measuring width
  • Checking dimensions

⚠️ Safety

Allow the tape to retract slowly to avoid damaging your fingers.

📖 Introduction

A hacksaw is a hand-operated saw commonly used for cutting metal, plastic and similar materials.

⚙️ Main Uses

  • Cutting metal pipes
  • Cutting plastic
  • Workshop cutting work

⚠️ Safety

Wear eye protection and keep your hands away from the blade while cutting.

⚠️ Basic Safety Tips

  • Always use the correct tool for the job.
  • Keep tools clean and in good condition.
  • Wear appropriate safety equipment.
  • Keep sharp tools away from your body.
  • Store tools safely after use.
