🔨 Hand Tools

Essential tools for everyday workshop work.

🔨

Hammer

Driving • Fitting • Breaking

INTRODUCTION

A hammer is a hand tool consisting of a weighted head attached to a handle. It is commonly used for driving nails, fitting parts and workshop operations.

Tool Type Hand Tool
Material Steel / Wood
Operation Manual
Primary Use Driving Nails

⚙️ Main Uses

  • Driving and removing nails
  • Fitting components
  • Light breaking work

🔧 Common Types

Claw Hammer Ball-Peen Sledgehammer Mallet

⚠️ Safety

Check that the head is securely attached to the handle. Wear suitable eye protection while working.

🪛

Screwdriver

Tightening • Loosening • Assembly

INTRODUCTION

A screwdriver is a hand tool designed to drive, tighten and loosen screws.

Tool Type Hand Tool
Material Steel
Operation Manual
Primary Use Screws

⚙️ Main Uses

  • Tightening screws
  • Removing screws
  • Assembly and repair

🔧 Common Types

Flat Head Phillips Torx Hex

⚠️ Safety

Always use the correct screwdriver size for the screw.

🔧

Pliers

Grip • Bend • Cut

INTRODUCTION

Pliers are hand-operated tools used for gripping, bending, holding and cutting different materials.

Tool Type Hand Tool
Material Hardened Steel
Operation Manual
Primary Use Gripping

⚙️ Main Uses

  • Holding components
  • Bending wires
  • Cutting wires

🔧 Common Types

Combination Long Nose Cutting Locking

⚠️ Safety

Use the correct type of pliers for the job. Never use pliers as a hammer.

🔩

Wrench

Tightening • Loosening • Maintenance

INTRODUCTION

A wrench is a hand tool used to tighten or loosen nuts, bolts and other fasteners.

Tool Type Hand Tool
Material Alloy Steel
Operation Manual
Primary Use Fasteners

⚙️ Main Uses

  • Tightening nuts and bolts
  • Removing fasteners
  • Mechanical maintenance

🔧 Common Types

Open End Ring Adjustable Socket

⚠️ Safety

Use the correct size wrench and make sure it is properly positioned on the fastener.

⚠️ Tool Safety First

Always select the correct tool for the job. Inspect tools before use, keep them clean and wear suitable protective equipment.
